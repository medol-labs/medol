# “感-通-算”一体化的跨域健康管理联邦孪生平台 安装部署手册

## 系统要求

### 联邦学习子系统

联邦学习子系统部署涉及 Web 前端、后端 接口（API） 服务、数据库/事件存储、对象或文件存储、任务调度/消息通道和运行时代理。基础操作系统、网络、证书、容器运行时和数据库要求建议在平台级安装部署手册中统一维护。

## 常用软件安装

本节建议沿用平台级基础软件安装说明，不按子系统重复拆分。联邦学习子系统如需额外运行时、代理或模型仓库依赖，可在最终合并稿中补充。

#### 九、启动与停止/FLP-DOC-SECTION-16

| 操作 | 命令 | 说明 |
| --- | --- | --- |

##### 12.2 常见问题/FLP-DOC-SECTION-21

| 问题 | 可能原因 | 检查方法 |
| --- | --- | --- |
| 页面打不开 | Web 前端、反向代理、DNS、TLS 或防火墙问题 | `docker compose ps web` / `systemctl status nginx` |
| 后端启动失败 | umadb 数据库或事件存储连接/配置失败 | 检查 DB_HOST、DB_PORT、DB_NAME=umadb、DB_USER、DB_PASSWORD |
| 登录失败 | 管理员或认证初始化未完成 | Check administrator initialization and authentication config |
| 外部依赖不可用 | 网络、DNS、凭据或白名单问题 | `nc -vz <host> <port>` and dependency logs |
