# OpenCode Runtime Adapter

Use OpenCode as a lightweight, open, provider-flexible local agent runtime.

## Adapter Contract

- Start or connect to an OpenCode server from the MEDOL service layer.
- Create one session per task or per workspace workflow.
- Send the task payload, selected skills, and relevant model files.
- Subscribe to runtime events and map completion back to `AgentResult`.

## Strengths

- Open source.
- Provider-flexible.
- JavaScript/TypeScript-friendly SDK.
- Suitable for embedding behind MEDOL task APIs.
