# 数据权限（DataAccess）

[总体说明](README.md) · [完整建模与配置](../access-policies.md)

```medol
import data-access
```

显式导入后，readmodel 的全局默认策略、字段重绑定和追加权限条件才生成运行时过滤。未导入时不启用，也不自动登记数据范围权限。该模块是应用级基础设施能力，不新增部署或管理页面。

IAM 属性及业务成员关系都先解析成授权值，再直接查询目标 readmodel 字段。具体语法、权限码和适配器契约见完整说明。

移除引用并重新导出、生成代码，会删除生成的数据范围运行时和自动配置。应用自行编写的适配器仍由应用维护，需要同步调整其依赖。
